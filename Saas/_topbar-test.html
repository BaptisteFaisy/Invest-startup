Authentification à deux facteurs (2FA)

Protégez votre compte avec Google Authenticator. À chaque connexion, un code à 6 chiffres vous sera demandé en plus de votre mot de passe.

Scannez ce QR code avec Google Authenticator (ou Authy), puis entrez le code pour confirmer.

Comptes cloud connectés

Connectez un compte Google Drive ou Dropbox pour envoyer vos documents de due diligence directement dans votre espace.

Data rooms spécialisées

Créez votre compte sur la plateforme de votre choix — Ansarada est gratuit pour démarrer — puis importez-y le ZIP structuré de votre dossier de due diligence. Aucune autorisation d’accès à votre compte liquid + n’est nécessaire.

Le ZIP contient les pièces disponibles, rangées par rubrique, prêtes à être importées dans la plateforme choisie.
